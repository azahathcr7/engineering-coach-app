# Privacy and data handling

- All workspace data is stored in browser localStorage under `engineering-coach-workspace-v1`.
- No account, server, database, analytics, telemetry, or external API is used by the app.
- Export creates a JSON file containing tasks, notes, journal entries, focus history, and preferences.
- Import replaces the current local workspace after a confirmation prompt.
- Clearing browser storage or using a different browser profile can make the data unavailable.
- Anyone with access to the same browser profile may be able to access the workspace.
- Do not store passwords, API keys, access tokens, customer personal data, secrets, or sensitive production incident details.
- Export backups to a private location and protect them appropriately.
